## Full description (4000)

Life Metric is a simple place to log blood pressure, body weight, and workouts — and see how they change over time.

Everything you enter stays on this phone. There is no account to create, no sign-in, and no cloud sync. Your readings never leave the device unless you export or share them.

BLOOD PRESSURE
Log systolic, diastolic, and optional heart rate with the date and time. Life Metric classifies each reading with AHA-style categories, shows a gauge and trend chart, and can average paired readings from the same visit. Set an optional target, add tags or notes, and turn on morning or evening reminders.

WEIGHT
Log weight in pounds or kilograms. Watch a 7-day trend, a history chart with an optional goal line, and BMI when height is set. Set a starting weight and a target, track waist if you want, and get an optional morning reminder.

WORKOUTS
Build plans for strength, cycling, and other activities. Log sets with last-time values filled in, optional RPE, warm-up / working / drop / failure tags, and a rest timer. Cycling sessions can include distance, time, resistance, speed, cadence, and heart rate. See weekly volume, personal records, and how this week compares with HHS activity guidance.

HOME
The dashboard shows the latest reading in each area, charts, and a quick path to add the next one.

YOUR DATA
Export or import a JSON backup, share a text or CSV report, or erase everything on the device. Optional reminders use notifications only if you turn them on.

Life Metric is a personal tracking tool. It is not a medical device and does not diagnose, treat, or prevent any condition. Always follow advice from a qualified healthcare professional.
